# migaki

Migaki (磨き, "polish") is a set of sense and taste references for making
output read as excellent rather than generic — sense being grounded in fact,
taste in preference. The guidance lives in three files in this
directory. Open **only the file you need** for the task at hand — do not read
all three by default.

- `core.md` — timeless perceptual principles that hold regardless of era.
- `slop.md` — patterns that read as AI-generated or dated; avoid these.
- `edge.md` — what reads as excellent right now.

## How to apply this

Taste is contested. Propose, don't impose.

Build the thing that was asked for. Alongside it, surface the specific taste
decisions as a short list the user can accept or reject individually — name the
pattern, state what it signals, and give the alternative. Keep each to a line
or two.

Do not narrate the principles. Do not restate what a file says. Do not lecture
on design theory. A decision the user can act on beats an explanation of why
it's correct.

Where a reference file conflicts with an explicit instruction from the user,
the user wins. Note the conflict once and move on.
